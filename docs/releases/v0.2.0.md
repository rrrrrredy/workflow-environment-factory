# Workflow Environment Factory 0.2.0

Version 0.2.0 is the first cross-platform lifecycle preview. It turns one confirmed repository or local Issue-to-PR demonstration into a base Case and two traceable variants, resets every attempt, and scores final code or simulator state with objective validators. Codex execution is enabled only where the no-model read-isolation preflight passes.

## Download

- Windows 11 x64: `workflow-environment-factory-0.2.0-windows-x64.zip`
- Linux x64 and Apple Silicon macOS: `workflow-environment-factory-0.2.0-portable.tar.gz`

Download the matching `.sha256` file, verify it before extraction, and inspect the platform installer. Windows uses `scripts/Install.ps1`; Linux and macOS use `scripts/Install.sh`. A reachable Docker daemon with Linux containers is required for task generation and execution.

## What changed

- Added ownership-safe Linux/macOS installation, service inspection, restart, uninstall, and explicit data deletion.
- Added a portable archive with the compiled UI and exact RunCase Interchange v0.1.2 schemas.
- Prevented concurrent execute requests from launching the same Run twice and serialized scoring per Run.
- Marked synthetic fixtures as `model_executed: false`; production scoring refuses them.
- Kept verifier workspaces read-only and rejects a Score when validation mutates the Agent workspace.

## Evidence attached

Hosted Ubuntu runs both real Docker environment gates and the extracted portable archive lifecycle. Hosted Apple Silicon macOS runs build, plugin, loopback service, restart, uninstall, and final-absence checks from the same portable archive. The Windows archive has a separate hosted lifecycle record whose Docker prerequisite is explicitly a command stub.

The Windows evidence also records the current Codex 0.151.0 deny-read ACL failure as `known_unsupported` with `agent_execution_supported: false` and `model_executed: false`. This keeps installation evidence distinct from Agent-execution support.

## Limits

Native Windows Codex Case execution is unavailable until its required deny-read preflight passes; there is no unsafe override. No physical Mac, Docker Desktop on macOS, ordinary user-owned clean machine, or authenticated Codex task Run was tested. macOS can install and run the local product, but Docker-backed task generation, execution, and scoring remain unverified there. This release is a prerelease, supports Codex only, and treats every Score as single-run evidence.
