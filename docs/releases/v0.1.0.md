# Workflow Environment Factory 0.1.0

This technical preview is for developers who want repeatable Codex tasks from their own repository or Issue-to-PR process instead of another public benchmark.

## What you can do

- Define one code Blueprint from a failing baseline and descendant known-correct revision.
- Record the minimum local Issue-to-PR workflow without connecting a production GitHub or Linear account.
- Admit a base Case only when baseline, correct-state, reset, and simulator-state checks discriminate objectively.
- Generate exactly two user-confirmed, source-linked variants.
- Give every Codex attempt a fresh repository and simulator snapshot, then separate task failure from timeout, crash, reset, validator, and environment failures.
- Export a portable three-Case task pack and objective Scores through RunCase Interchange.

## Install

Use the attached `workflow-environment-factory-0.1.0-windows-x64.zip` and matching `.sha256` file. Verify the checksum, extract the archive, inspect `scripts/Install.ps1`, and run the installer from a normal Windows Terminal or PowerShell session. Docker Desktop must be running with Linux containers before installation.

## Evidence attached to this release

- A commit-, protocol-, Docker-image-, and authenticated-evidence-bound release manifest.
- GitHub build-provenance attestations for the archive, manifest, and evidence files.
- Sanitized real Codex product-gate evidence for one code Run and one Issue-to-PR Run.
- Deterministic Docker evidence proving reset and objective discrimination for both verticals.
- Sanitized Windows archive-installation evidence covering injected install/repair failures, loopback service and Codex plugin registration, preservation, explicit deletion, and final absence.

The Ubuntu Docker gate and Windows installation gate are complementary. They are not represented as the separate single-host Windows 11 + Docker Desktop acceptance required before a stable label.

## Preview boundary and removal

Version 0.1 supports Windows 11, Docker Desktop Linux containers, and Codex only. It does not clone arbitrary SaaS products, use production accounts, hide baseline repository tests, train a model, or accept unreviewed generated tasks. Scores are single-run evidence.

Review `docs/security-and-data.md`, `docs/known-limitations.md`, and `docs/acceptance.md` before using the product. Run `scripts/Uninstall.ps1` to remove the service registration, Codex plugin, marketplace entry, and optional Startup shortcut while preserving product data. Use `-DeleteData` only as a separate explicit choice, then run `scripts/Inspect-Installation.ps1 -RequireAbsent -RequireNoData` for machine-readable zero-residue proof.
