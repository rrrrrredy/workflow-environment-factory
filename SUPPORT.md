# Support

Use [GitHub Issues](https://github.com/rrrrrredy/workflow-environment-factory/issues) for reproducible product bugs, installation problems, and narrowly scoped feature requests.

Before opening an issue:

1. read the [installation guide](docs/installation.md) and [known limitations](docs/known-limitations.md);
2. run `wef doctor` from the project virtual environment or `scripts\Check.ps1` when appropriate;
3. remove tokens, private paths, repository content, prompts, and production data from logs;
4. include the product commit/version plus Windows, Docker, Python, Node, Git, and Codex versions;
5. state whether the failure was Case generation, reset, Agent execution, validation, cleanup, or UI presentation.

Security-sensitive reports follow [SECURITY.md](SECURITY.md), never a public issue.
